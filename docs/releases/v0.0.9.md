Continuum 0.0.9：对话只上下滚动，不再左右滑动；回答的 Markdown 显示更完整。

0.0.8 打了标签但没有发布成功（一个界面测试在较慢的机器上点击超时），这一版内容和 0.0.8 相同，加上了这个测试修复。

## 更新

装了 0.0.6 或之后版本的会自动更新到这一版（窗口底部提示“重启并更新”，或下次退出时自动装上）；也可以在设置 → 版本里点“检测更新”。

## 改了什么

- **不再左右滑动**：长命令、长输出、宽表格、长链接都按窗口宽度换行，整个对话只上下滚动。
  - 步骤标题里的命令最多显示两行，点开这一步能看到完整命令和输出。
  - 表格固定在可用宽度内，单元格内容自动换行。
- **Markdown**：在原来的标题、列表、表格、粗体、行内代码之外，加了代码块（```）、引用（>）、分隔线、斜体、链接。链接点了用系统浏览器打开，不会在应用里跳转。所有内容都先转义再解析，回答里的 HTML 只当文字显示。
