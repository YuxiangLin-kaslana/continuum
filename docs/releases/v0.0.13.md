Continuum 0.0.13：对话页只剩对话，加了搜索；项目和 Worker 收进一个标签。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 改了什么

- **对话页只是一个对话框**：没有左边栏，消息上也不再挂项目标记。项目的提议、提醒照常出现在对话里。
- **搜索**：对话顶部的搜索框搜全部历史（在服务器上搜，不只是已加载的部分）。结果里标出命中的字，点一下跳到那条消息并闪一下；比较早、还没加载的消息直接在结果里展开全文。Esc 清空。
- **“项目”标签**装下其余的一切：
  - 顶部切换“项目 | Worker”；原来的 Worker 标签并进来了。
  - 点开一个项目：它的目标、安排、状态和操作，下面是这个项目自己那部分对话，也可以在这里直接对它说话（仍然算在主对话里）。
- 修了：项目页每组从第二张起的卡片没有“打开”按钮。
