Continuum 0.0.12：项目。频道和工单都不见了，换成一条主对话加项目。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **一条对话**：你只和主 agent 说话。所有消息都在“主对话”里，每条带着它属于哪个项目的标记，点标记就进入那个项目。
- **项目**：
  - 一次性项目：你交代一件事，它就是一个项目；做完自动归档。
  - 长期项目：要长期做、定期检查、到时提醒的事，助理会在对话里提议一个长期项目（目标、它可以自己做什么、什么时候做），你点“确认开始”才生效。之后它按安排在主对话里提醒你，或者自己开工；多次运行共用一个工作区和一份笔记，越做越了解情况。
  - 在项目里说话：点进左边的项目，说的话直接交给它（仍然在主对话里）。
  - 时间按你电脑的时区。
- **项目页**（原来的“工单”）：等你处理的在最前（等你确认的提议、等你回答的问题），然后是长期项目（下一次什么时候、运行了几次，可以暂停、继续、结束），进行中的一次性项目，已归档的。
- 左边栏：主对话、长期项目、进行中的项目，已归档的收起来。

## 服务器这边

- 新接口：`GET /api/v1/messages`、`GET /api/v1/steps`、`GET /api/v1/projects`、`POST /api/v1/projects/{id}/confirm|refuse|pause|resume|end`、`PUT /api/v1/me/timezone`。
- 修了：长期项目的几次运行共用工作区时，Worker 的对话记录和工具会话会混在一起。
