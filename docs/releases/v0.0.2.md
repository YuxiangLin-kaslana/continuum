Continuum 0.0.2：账号密码登录，新 logo 和新界面。

## 下载

`Continuum-Setup-0.0.2.exe`，覆盖安装 0.0.1 即可。安装包还没有代码签名，Windows SmartScreen 可能拦一下：点“更多信息”→“仍要运行”。

## 新的

- **账号密码登录**：用户名和密码登录，不用再粘贴令牌。服务器地址默认是 `https://ai-api.yuxianglin.xyz`，要换的话展开“更换服务器”。登录后这台设备会拿到自己的令牌，用系统加密保存；点“退出”会通知服务器作废它。同一个账号连续输错 5 次，会锁 10 分钟。
- **新 logo**：开口的无穷符号和 continuum 字标。
- **新界面**：高空暮色的渐变（靛蓝、紫、玫瑰、琥珀），宽字距的细标签，半透明面板；无边框窗口，自带标题栏，可以拖动、最小化、收进托盘。
- 工单改叫任务：每个任务有编号，等你处理的排在最前，需要你拍板的问题单独标出来。

## 服务器这边

- 新命令 `continuum user passwd <名字>` 设置或修改密码；密码只存加盐的 scrypt 哈希。
- 旧的令牌照样能用，0.0.1 不受影响。

## 已知限制

- 只有 Windows 版；没有自动更新。
- 桌面端里还不能改密码，要在服务器上用命令改。
