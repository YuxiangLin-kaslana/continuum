Continuum 0.0.15：一次改完所有服务器的执行权限；更多任务可以同时跑。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **设置 → SSH 服务器 → 全部服务器的执行权限**：选一项，点“应用到全部”（要点两次确认），所有服务器一次改完，不用逐台编辑。
- 等你批准远程命令时，不再同时显示“思考中…”。

## 服务器这边

- 同时运行的 Worker 上限改为 30：发完一件事马上可以发下一件，它们各自同时进行。
- 调度器最多同时判断 16 条消息，Worker 交回的结果最多同时处理 8 个，连续发很多条也不用排队等。
- 修了：服务在 Worker 执行工具的半途中重启，恢复时会因为对话记录不完整而被模型拒绝（HTTP 400），工单就卡住了。现在会先补上“这次调用被中断了”，Worker 会重新执行需要的命令。
