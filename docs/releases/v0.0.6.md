Continuum 0.0.6：自动更新。

## 下载

`Continuum-Setup-0.0.6.exe`。**这一版需要手动覆盖安装一次**；从这一版起，以后的新版本会自动更新。安装包还没有代码签名，Windows SmartScreen 可能拦一下：点“更多信息”→“仍要运行”。

## 新的

- **自动更新**：应用启动时、之后每 4 小时，去 GitHub Releases 看有没有新版本；有就在后台下载。下载好后：
  - 窗口底部出现“新版本 x.y.z 已下载好”和“重启并更新”按钮，点了马上换成新版本；
  - 不点也行，下次退出应用时自动装上。
- 设置页里显示当前版本和更新状态。

## 构建

- 发布时除了安装包，还上传 `latest.yml` 和 `.blockmap`，已安装的应用靠它们判断和下载新版本。
- 仓库已经公开，应用不需要任何令牌就能读到新版本。

## 已知限制

- 安装包没有代码签名，Windows 可能在更新时提示来源未知。
- 只有 Windows 版。
