Continuum 0.0.3：新界面，回答流式输出，能看到助理执行的每一步。

## 下载

`Continuum-Setup-0.0.3.exe`，覆盖安装 0.0.2 即可。安装包还没有代码签名，Windows SmartScreen 可能拦一下：点“更多信息”→“仍要运行”。

## 新的

- **纯黑新界面**：左边是频道列表，右边是当前对话；可以新建对话，有新消息的频道会标出来。窗口默认 520×780，可以最大化。
- **AI 回答不加框**：助理的回答直接写在背景上，只有你自己的消息带气泡。回答里的标题、列表、表格、粗体、代码会排好版；回答内容只当文字显示，不会被当成网页执行。
- **流式输出**：助理写回答时，文字边写边出现，末尾有光标；写完换成正式回复。
- **看得到每一步**：助理思考、运行命令、读写文件，都收在一行“已执行 N 个步骤”里，点开能看到每条命令和它的输出。执行中显示“正在运行命令…”。这些步骤会保存，重开窗口还在。
- **生成头像**：没有头像时按名字画一个。你的头像是 4 分对称，助理的是 8 分对称；同一个名字永远是同一张图。
- **工单页**：分成等你处理、执行中、已结束三组；需要你回答的问题单独标出，点“去回答”直接跳到对应的对话；停止要点两次。
- **登录页**：服务器地址默认填好；密码可以点小眼睛显示；下面有连接状态。
- 措辞统一为代理助理（Agent Assistant）。

## 服务器这边

- 助理调用模型改成流式；步骤和流式文字通过原来的 WebSocket 推送，新增 `GET /api/v1/threads/{thread}/steps`。
- `continuum user passwd` 新增 `--allow-short`，可以设置少于 8 位的密码（更容易被猜中；登录失败照样限流）。

## 已知限制

- 只有 Windows 版；没有自动更新。
- 还不能上传文件、不能自定义头像。
- 桌面端里还不能改密码，要在服务器上用命令改。
