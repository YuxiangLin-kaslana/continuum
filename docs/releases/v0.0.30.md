Continuum 0.0.30：Claude Code 和 Codex 也有这台机器的完全权限。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 改动

- 助理有这台机器的完全权限时（0.0.29 起），它叫来的 Claude Code 和 Codex 也一样：不再套隔离层，不再在命令沙箱里运行，也不再逐条请求许可。它们可以联网、sudo、读写任何文件，用本机的 gcloud、aws、gh、docker、systemctl。
- 这是全局设置：每个项目、每个 Worker、每个子 Worker 都适用，不只是某一个任务。
