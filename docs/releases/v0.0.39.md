Continuum 0.0.39：自定义提示词开关（DSH）。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 新的

- 输入框左边多了一个 **DSH** 开关。服务器上装了提示词时才会出现，默认关闭。
- 打开后，助理每次调用模型时，都把这段提示词放在整个上下文的**最末尾**：项目负责人、子 Worker、步数用完时的最后总结都算在内。
- 注入只对当次调用生效：不写进对话记录，不进入之后的上下文，下一次调用重新在末尾加一次。
- 提示词只保存在服务器上，App 和接口只显示它的名字和字数，不显示内容。
- 开关按账号分别保存，切换后下一次模型调用就生效。
