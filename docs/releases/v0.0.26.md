Continuum 0.0.26：连邮箱更不容易填错，连不上会说清楚为什么。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- 邮箱类型多了 **QQ 邮箱、网易邮箱（163 / 126）、iCloud**。
- 填邮箱地址时，类型会自动选对（比如填 @outlook.com 就切到 Outlook），下面会提示这家邮箱要去哪里拿应用专用密码或授权码。

## 修好的问题

- 地址和类型对不上（比如 outlook.com 的地址选了 Gmail，结果拿 Outlook 的账号去登录 Gmail 服务器）时，会直接告诉你该选哪个，不再报一行看不懂的 `b'[AUTHENTICATIONFAILED] …'`。
- 邮箱拒绝登录时用中文说明原因和办法。outlook.com / hotmail / live 个人邮箱：微软从 2024 年 9 月起已不允许用密码或应用密码登录 IMAP，会直接这样提示。
