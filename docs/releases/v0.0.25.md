Continuum 0.0.25：每个工具都可以连多个账号；助理的回答不会再丢。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **一个工具，多个账号**：工具页里每个工具列出它的所有账号（比如“公司”“个人”两个邮箱、两个 GitHub、多个 AWS 账号），每个都可以测试、修改、断开；下面“＋ 添加账号”再连一个。原来连好的那个自动变成“默认”账号。
- 助理知道每个工具连了哪几个账号；你说“用工作邮箱发”，它会用那个账号。没说的话用第一个。
- 左边的列表会写“2 个账号”，有连不上的也会标出来。

## 修好的问题

- 助理有时把答案直接写成一段话、没有正式汇报，这段答案就没有送到你那里，项目一直挂着（比如“你能看到我的 GitHub 吗”）。现在这样写出来的答案也会交给你。
