Continuum 0.0.42：回答里的文件路径可以点开预览。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 新的

- 回答里提到服务器上的文件（比如 `/home/ec2-user/continuum-home/work/…/PP-ERP-修改进度.md`）时，路径变成可点的链接。
- 点开后在窗口里预览：Markdown 排好版（表格、图表、流程图都会画出来），图片、表格（csv）、代码和文本、音视频也都能看。可以“打开”（用电脑上的程序）或“另存为”。Esc 或“关闭”退出。
- 只能打开你自己的项目和工作目录里的文件，服务器上的其他文件打不开。
- 助理提到文件时会写完整路径，方便你点开。
