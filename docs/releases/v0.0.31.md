Continuum 0.0.31：DeepSeek 调度，单台服务器上的事交给那台服务器上的 Claude Code / Codex。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 新的

- **按范围分工**：DeepSeek 负责调度。
  - 只涉及一台服务器的事：交给那台服务器上的 Claude Code（优先）或 Codex，在那台机器上直接做（有那台机器的完全权限，看得到那里的代码、服务和日志）。
  - 只涉及 Continuum 自己这台机器：交给本机的 Claude Code / Codex。
  - 要跨多台服务器协调：由 DeepSeek 和它派出的 Worker 用 ssh 来做。
- 巡检服务器时会顺便查它装了哪些编程助手、有没有登录；调度器每次都知道哪台能用哪个。登录失效的会标出来，不再往那里派活。
- 服务器上的助手做的每一步（命令、读写文件）照常显示在“查看过程”里；对话里会显示“crm 上的 Claude Code 正在处理…”。
- 执行权限不是“全部自动”的服务器，交给那里的助手前会先请你批准。
