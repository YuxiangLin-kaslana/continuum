Continuum 0.0.19：主对话里只看到分配器和项目的结果，干活的过程在项目里。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 改了什么

- **分配器不亲自干活**：你交代一件事，分配器回一句“好，我开一个项目去做……，做完告诉你”，然后由项目去干；做完，项目把结果交回主对话。
- **主对话里每个项目的工作只占一行**：项目名 + 现在在做什么（“正在远程命令…”“3 个 Worker 正在同时干活…”“已执行 5 个步骤”），右边“查看过程”打开项目页，看每一步命令和输出。
- 需要你批准的远程命令仍然出现在主对话里（只有那一条），可以直接批准或拒绝。
- 分配器把消息转给已有项目时，你的消息下面会注明“交给项目「…」”。
