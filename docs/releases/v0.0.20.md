Continuum 0.0.20：设置里可以连接 GitHub、邮箱、Slack、Google、Cloudflare、GoDaddy；做完的项目不再一直显示“运行中”。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **设置 → 工具**：每个工具一张卡片，写着去哪里申请凭据。填好点“保存并测试”，会显示连上的账号；也可以单独“测试”或“断开”。
  - GitHub：个人访问令牌。助理可以用 gh 查 PR、issue、提交，必要时评论、建 issue。
  - 邮箱：Gmail / Outlook 或自定义服务器，用应用专用密码。助理可以搜索、读邮件，在你明确要求时发邮件。
  - Slack：机器人令牌（xoxb-）。助理可以读频道、发消息。
  - Google：服务账号 JSON 密钥。助理可以用 gcloud 管 Google Cloud，读写共享给服务账号的 Drive、Docs、Sheets。
  - Cloudflare：API 令牌。GoDaddy：API Key + Secret。助理可以查、改域名和 DNS 记录。
- 凭据只存在服务器上，不会再显示出来；工具输出里如果带出了凭据，会换成 `***`。
- 对话和项目页里，这些工具的每次调用都显示成一个步骤。

## 修好的问题

- 做完一轮、却没正式结束的项目，以前会一直显示“运行中”；现在空闲 2 小时自动归档，之后再提起照样能接着做。
- 模型调用失败时，项目会出现在“等你处理”里，回一句或点“重试”就能接着做。
