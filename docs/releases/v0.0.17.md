Continuum 0.0.17：项目负责人同时派出多个 Worker。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **项目负责人**：每个项目的第一个 Worker 是负责人。能拆开同时做的事（比如同时检查多台服务器），它会一次派出多个 Worker 同时去做，等都做完后检查、汇总成一个完整的答复；简单的事它自己做。
- 对话里显示“派出 N 个 Worker”这一步，运行时顶上写“N 个 Worker 正在同时干活…”；每个子 Worker 的步骤前面标着它的名字。
- Worker 页多了“子 Worker”一组：每个子 Worker 属于哪个项目、在做什么、当前哪一步、跑了多久；排队等空位的也会显示。

## 服务器这边

- 所有项目的子 Worker 共用 30 个名额，多出来的排队。
- 全部测试控制在 1 分钟以内（现在约 25 秒），超过就判失败。
