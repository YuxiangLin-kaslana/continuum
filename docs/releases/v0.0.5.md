Continuum 0.0.5：设置页里管理 SSH 服务器；助理能把编程活交给 Claude Code 和 Codex。

## 下载

`Continuum-Setup-0.0.5.exe`，覆盖安装即可。安装包还没有代码签名，Windows SmartScreen 可能拦一下：点“更多信息”→“仍要运行”。

## 新的

- **设置页**：右上角齿轮进入。“SSH 服务器”一栏：
  - 显示 Continuum 的公钥和指纹，一键复制公钥，或复制整行 `authorized_keys`（带 `from="13.134.76.110"` 等限制）。
  - 添加、编辑、删除服务器：名字、地址、端口、登录用户、经过哪台跳板、执行权限（每条命令都先问你 / 只读直接执行 / 直接执行）、备注。
  - “测试连接”：在服务器上执行 `hostname`，记下是否连通、主机指纹；连不上时说明原因（超时、公钥没认、指纹变了……）。
  - 只有管理员（服务器设置里的 `[ssh] admins`）能看到和修改。
- **Claude Code 和 Codex**：DeepSeek 助理遇到较大的编程活时交给它们，步骤里显示为“交给 Claude Code / 交给 Codex”，运行时顶上显示“Claude Code 正在处理…”。

## 服务器这边

- DeepSeek 负责调度和普通工作；`[executor.config.claude_code]`、`[executor.config.codex]` 让它可以调用你自己账号登录的 Claude Code 和 Codex。两者的进程都隔离运行，看不到服务器上的密钥和 `~/.ssh`，命令不能联网。
- 新的 `[ssh]` 设置和 `/api/v1/ssh` 接口；服务器列表写成 Continuum 自己的 ssh_config，主机指纹首次连接时记下，之后变了就拒绝。
- 修了路由器偶尔把请求当成“忽略”、不回复的问题。

## 已知限制

- 助理还不能在这些服务器上执行命令（下一步：受控的 `ssh` 工具和批准流程）。
- 只有 Windows 版；没有自动更新。
