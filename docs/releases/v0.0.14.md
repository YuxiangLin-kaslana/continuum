Continuum 0.0.14：项目；对话页只剩对话，加了搜索；主 agent 统一调度每条消息。

0.0.12 和 0.0.13 打了标签但没有发布成功（一个界面测试在较慢的机器上不稳定），它们的内容都在这一版里。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **对话页只是一个对话框**：没有左边栏和项目标记；项目的提议、提醒照常出现在对话里。
- **搜索**：对话顶部的搜索框搜全部历史（在服务器上搜），标出命中的字；点一下跳到那条消息，较早未加载的直接在结果里展开。Esc 清空。
- **项目**（取代频道和工单）：
  - 一次性项目：你交代一件事，它就是一个项目，做完自动归档。
  - 长期项目：要长期做、定期检查、到时提醒的事，助理在对话里提议（目标、它可以自己做什么、什么时候做），你点“确认开始”才生效。之后它按安排在对话里提醒你，或者自己开工；多次运行共用一个工作区和一份笔记。时间按你电脑的时区。
- **“项目”标签**装下其余的一切：切换“项目 | Worker”；点开一个项目看它的目标、安排、操作和它自己那部分对话，也可以在那里直接对它说话。
- **主 agent 统一调度**：每条消息先由主 agent 判断，是新的一件事、某个项目的后续（比如“刚才那个结果再乘以 2”会交回同一个项目，它记得之前做过什么），还是客套话。之前一条消息会同时唤醒对话里所有旧的工作、各做一遍，这个问题修好了。

## 服务器这边

- 新接口：`GET /api/v1/messages`、`GET /api/v1/steps`、`GET /api/v1/search`、`GET /api/v1/projects`、`POST /api/v1/projects/{id}/confirm|refuse|pause|resume|end`、`PUT /api/v1/me/timezone`。
