Continuum 0.0.48：主模型换成 Claude（claude -p）。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 改动

- **分配器**（收到消息后判断开新项目还是转给已有项目）改由 Claude 来判断。
- **负责人和子 Worker** 改由 Claude Code 来做：
  - 本机的命令和文件用它自带的工具。
  - Continuum 的工具也都能用：服务器和远程命令批准、服务器上的编程助手、派子 Worker、发文件给你、看视频听音频、记忆、长期项目、GitHub / Slack / 邮箱 / GCP 等。
  - 每一步照常显示在“查看过程”里，回答照常边写边出来。
  - Claude 自己就能看图片。
- **DeepSeek 只做后备**：Claude 额度用完、登录失效、出错或超时时，那一轮自动交给 DeepSeek，不会卡住。
- 同时运行的 Claude 最多 6 个；超出时，子任务改由 DeepSeek 来做。

## 注意

- 每句话的第一声回应会从 2 秒左右变成 5–7 秒。
- 用的是这台服务器上登录的 Claude 订阅，受它的用量上限约束。
