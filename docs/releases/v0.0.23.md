Continuum 0.0.23：“工具”标签，所有工具在一处。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **“工具”标签**（对话、项目旁边）：左边是全部工具，分成“服务器”“编程助手”“服务”三组，每个带图标和状态，上面可以搜索；右边是选中的工具：它是什么、助理能用它做什么、现在的状态和操作。
  - SSH 服务器：原来设置里的公钥、批量执行权限、服务器列表、巡检，都搬到这里。
  - Claude Code、Codex：显示服务器上装没装、登录的是哪个账号；可以一键停用或启用，停用后助理不会再把活交给它。
  - GitHub、邮箱、Slack、Google（GCP / Drive / Docs）、Cloudflare、GoDaddy、AWS：连接、测试、断开都在这里。
- 设置里只留版本和检测更新。
