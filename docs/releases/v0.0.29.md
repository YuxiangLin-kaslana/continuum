Continuum 0.0.29：助理对 Continuum 所在的机器有完全权限；gcloud 能用了。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 新的

- **这台机器的完全权限**（设置 `[executor.config.sandbox] kind = "host"`）：Worker 的命令直接在 Continuum 所在的主机上执行，可以联网、可以 sudo、能读写任何文件，能用本机的 gcloud、aws、gh、docker、systemctl，也能改 Continuum 自己的代码并重启。以前它在一个没有网络的沙箱里，只能说“我做不到，你自己去跑”。
- 文件工具（读、写、列目录）在这个模式下可以用绝对路径访问任何位置。
- 服务自己的 API 密钥不会出现在命令的环境变量里。

## 修好的问题

- gcloud 工具每次调用都报错 `'str' object is not callable`：程序路径和工具方法用了同一个名字。现在用连接的 Google 服务账号能正常跑 gcloud。
