Continuum（续）的第一个版本：Windows 桌面端，连接你自己的 Continuum 服务器。

## 下载

`Continuum-Setup-0.0.1.exe`。安装包还没有代码签名，第一次运行时 Windows SmartScreen 可能拦一下：点“更多信息”→“仍要运行”。

## 第一次打开

- 服务器地址：你的 Continuum 服务器，例如 `https://ai-api.yuxianglin.xyz`
- 令牌：管理员在服务器上用 `continuum user add <名字> --device <设备>` 生成，只显示一次

令牌用 Windows 的系统加密（DPAPI）保存在本机，界面拿不到。

## 能做什么

- **对话**：交代一件事或问一个问题，几秒内收到一句确认，做完收到结果。同一个对话里追加的话交给原来的工单，比如“再改成前 15 个”。
- **工单**：等你处理的排在最前（等你回答、等你看结果、卡住、失败），可以停止或重试；它问你问题时，点“去回答”在对话里回一句就能让它接着做。
- **常驻**：关掉窗口留在托盘；`Ctrl+Shift+Space` 呼出或隐藏；窗口不在前台时，新回复和需要你拍板的问题弹系统通知。

## 服务器这一版

- 模型 Router（DeepSeek）判断接不接，agent Worker 在沙箱里写代码、跑命令、交付结果；沙箱只能读写本工单的目录，默认没有网络。
- 工单、授权和恢复的规则移植自 dsh-superagent：进程中途被杀掉，重启后接着做，已发出的消息不会再发。

## 已知限制

- 只有 Windows 版。
- 安装包未签名；没有自动更新，新版本要重新下载安装。
- 还不能看到 Worker 产出的文件，只能看它在回复里说明的路径。
