Continuum 0.0.22：连接 GitHub、邮箱、Slack、Google、Cloudflare、GoDaddy、AWS；助理缺工具时直接在对话里找你要。

0.0.20 和 0.0.21 打了标签但没有发布成功，它们的内容都在这一版里。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **设置 → 工具**：GitHub、邮箱、Slack、Google（Cloud / Drive / Docs）、Cloudflare、GoDaddy、AWS，每个一张卡片，写着去哪里申请凭据。填好点“保存并测试”，会显示连上的账号；也可以“测试”或“断开”。
  - AWS 只用你给的 Access Key，不会用服务器自己的 AWS 身份，权限就是这把密钥允许的那些。
- **助理缺工具时直接找你要**：一件事需要一个还没连接的工具，或者你让它“加上某个权限”，主对话里会出现一张卡片，写明要它做什么、去哪里申请。你在卡片里填，凭据直接存到服务器，不进对话，也不发给模型；连上后助理马上接着干。
- 凭据只存在服务器上，不会再显示出来；工具输出里如果带出了凭据，会换成 `***`。
- 这些工具的每次调用都在项目页里显示成一个步骤。

## 修好的问题

- 做完一轮、却没正式结束的项目，以前会一直显示“运行中”；现在空闲 2 小时自动归档，之后再提起照样能接着做。
- 模型调用失败时，项目会出现在“等你处理”里，回一句或点“重试”就能接着做。
- 服务器刚重启的一段时间里，定时检查（项目提醒、服务器每日巡检、空闲归档）会被推迟，现在一开机就正常运行。
- 在卡片里填到一半时，对话里来了新消息，已经填的内容不会再被清空。
