Continuum 0.0.34：对话里能显示图片、图表、流程图、公式和文件。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 新的

**助理能把文件直接发到对话里**
- 图片（png / jpg / gif / webp / svg）直接显示，点一下放大，Esc 或再点一下关闭。
- 视频、音频可以直接播放。
- 表格（csv）显示前 40 行，文本和代码文件显示前 300 行并高亮。
- PDF 和其他文件显示成卡片，可以“打开”（用电脑上的默认程序）或“另存为”。
- 文件可以在 Continuum 这台机器上，也可以在你的任意一台服务器上，助理会取回来给你看。比如它用 Python 画的图、网页截图、服务器上的日志和报告。
- 文件只有你自己的设备能取到。

**回答里的内容画出来**
- 代码按语言高亮。
- 流程图、架构图、时序图（Mermaid）直接画成图，点一下放大。
- 数据对比、趋势、占比画成图表（柱状图、折线图、饼图等）。
- 数学公式（`$E=mc^2$`、`$$…$$`）。价格写法像 `$5 和 $10` 不会被当成公式。
- 回答里的网络图片直接显示。

助理也知道这些能力了：对比数据会用表格和图表，讲流程会画图，生成的图片和报告会直接发给你，而不是只告诉你文件路径。
