Continuum 0.0.49：打字不再卡。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 修好的问题

- **打字卡顿**：以前项目在后台跑的每一步（跑一条命令、思考中、做完）都会让对话页从头重画一遍。对话长、项目多的时候，页面几乎一直在重画，打字就会卡。现在：
  - 后台的这些动静不再重画对话页，只有出现要你批准的命令时才更新。
  - 一连串的更新合并成一次再画。
  - 画过的消息直接复用，不再重新生成。
  - 输入框由浏览器自己按内容长高，不再每打一个字就重新排版整页。
- 实测：对话 400 条、后台每秒 20 个步骤、同时打字，画面刷新间隔从平均 750 毫秒降到 17 毫秒（每秒 60 帧）。
