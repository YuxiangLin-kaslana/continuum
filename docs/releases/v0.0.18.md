Continuum 0.0.18：服务器概况；思考步骤不再重复。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。

## 新的

- **服务器概况**：每台服务器连通后，Continuum 自动做一次只读巡检：上面运行的服务、容器、端口、定时任务，以及代码仓库当前的分支、最近在做的功能、有没有没提交的改动，再整理成一份概况。每天自动更新一次。
  - 设置 → SSH 服务器：每台机器下面可以展开“服务器概况”，也可以点“巡检”或“重新巡检”马上看一次。
  - 助理派活时会先看这份概况，知道去哪台机器、那里跑着什么、在开发什么。
- 连着两次思考（中间只隔着界面上不显示的动作）合并成一条“思考了 N 秒”，不再显示成两条。

## 服务器这边

- 所有登记的服务器都改成了“直接执行”：助理在上面执行命令不再等批准。新加的服务器默认还是“每条命令都先问你”，添加时可以选。
