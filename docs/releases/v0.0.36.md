Continuum 0.0.36：复杂任务更可靠地交给工作机。

## 更新

装了 0.0.6 及之后版本的会自动更新，也可以在设置 → 版本里点“检测更新”。服务器端已经更新。

## 改动

- 调度器动手前先判断“在哪做、谁来做”：一两条命令的查询自己做；某台服务器上的排查和修改交给那台的编程助手；不属于哪台服务器的复杂工作（写代码、搭原型、抓取和处理数据、构建）交给工作机。
- 工作机按“有登录的编程助手、空闲内存多、负载低、不是生产机”自动挑选，目前首选 parts-catalog-deploy，其次 omanus、parts-scraper。
- 在工作机上做完的产物（文件、截图）会取回来发给你。
